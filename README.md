## 便宜台湾VPS的三处代价

**IP 属性。** 低价台湾套餐给的多是机房向路由宣告的台湾地理位置 IP，不是台湾住宅 IP。面向台湾本地用户的普通业务，这种 IP 够用；严格识别住宅 IP 的流媒体服务可能直接失效。想拿到本地属性，得往 HINET 那一类节点走，价格也在另一个量级。

**回程线路。** 第三方对台北低价机房的实测里，有一组数字可以做参照（样本是 ByteVirt 台湾 Lite 系列）：全国平均延迟约 214ms，其中移动约 132ms、联通约 179ms、电信约 305ms 且部分时段丢包约 12%，港澳台本地约 15ms。原因不是机器坏了，是去程路由不同：电信绕美国洛杉矶再回台北，联通走 AS4837 经日本大阪，移动走 CMI 经香港。同一台机器，三个人测出三个结果，说的就是这件事。

**带宽数字与实际速度。** 端口带宽是机房侧的能力，跨境能跑多少取决于运营商互联和晚高峰拥塞。同样标称 500Mbps 的机器，晚高峰实测掉到十几 KB/s 的情况是存在的。这也解释了为什么"标称 2000M 端口"不能当成"你下载能到 2000M"。

Akile TWLite 在第三点上的处理值得单独说：超量后限速到 10Mbps，而不是常见的 1Mbps。1Mbps 基本等于告别所有大文件操作，10Mbps 还能维持 SSH、监控上报、低码率网页和代码拉取，业务不会立刻断掉。真到了必须恢复全速的时候，¥20 重置一次 Mini 的流量，比再开一台机器便宜。
